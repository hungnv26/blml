Installing

  1. Tap the download button above.
  2. When the download finishes, open the file.
  3. Your phone will ask if it can install apps from the browser — allow it. That question appears because BLML comes from our own server rather than the Play Store, which is the point.
  4. Open BLML and sign in, or sign up with the invite code you were given.

On iPhone? Get BLML through TestFlight instead.
